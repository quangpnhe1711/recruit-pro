==========================================================
OpenAiCopilotProvider - Detailed Analysis
==========================================================

1. OVERVIEW
----------------------------------------------------------

OpenAiCopilotProvider là implementation của IAiCopilotProvider.

Mục đích của service này là đóng vai trò cầu nối giữa ATS System và AI Provider (OpenAI, Gemini, Azure OpenAI, OpenRouter hoặc bất kỳ OpenAI-compatible API nào).

Service hỗ trợ 2 chức năng chính:

1. Candidate Ranking
   - Nhận JD, Rules, Candidate Pool
   - Gửi dữ liệu sang AI
   - AI đánh giá và xếp hạng ứng viên

2. Recruiter Copilot Chat
   - Recruiter đặt câu hỏi bằng ngôn ngữ tự nhiên
   - AI trả lời dựa trên dữ liệu JD và Candidate Pool

Toàn bộ giao tiếp với AI đều đi qua service này.

----------------------------------------------------------
4. TryCreateRankingAsync
----------------------------------------------------------

Mục đích:

Thực hiện AI Ranking.

Input:

- Candidate Pool
- Normalized Rules
- Deterministic Ranking
- User Prompt
- Conversation Id

Output:

CopilotPromptResponseDto

Flow tổng quát:

Job + Rules + Candidates
            ↓
      Build Prompt
            ↓
       AI Provider
            ↓
      Parse Result
            ↓
CopilotPromptResponseDto

----------------------------------------------------------
Bước 1: Validate AI Configuration
----------------------------------------------------------

if (!_settings.Enabled || string.IsNullOrWhiteSpace(_settings.ApiKey))

Kiểm tra:

- AI có được bật hay không
- API Key có tồn tại hay không

Nếu không:

return null

Lý do:

Cho phép ATS fallback về deterministic ranking.

----------------------------------------------------------
Bước 2: Candidate Limitation
----------------------------------------------------------

int candidateLimit = ...

Giới hạn số lượng ứng viên gửi sang AI.

Ví dụ:

MaxCandidatesForAi = 20

=> Chỉ gửi 20 ứng viên đầu tiên.

Mục đích:

- Tiết kiệm token
- Giảm chi phí
- Tránh context overflow

----------------------------------------------------------
Bước 3: Build Payload
----------------------------------------------------------

Tạo object payload:

{
    job,
    userPrompt,
    normalizedRules,
    candidates,
    deterministicRanking
}

Đây là toàn bộ dữ liệu AI được phép nhìn thấy.

----------------------------------------------------------
Bước 4: Build Prompt
----------------------------------------------------------

BuildPrompt(payload)

Sinh prompt ranking.

Prompt yêu cầu:

- Trả đúng schema
- Không bỏ sót ứng viên
- Mỗi candidate phải có summary
- Auto reject phải nằm cuối
- Trả JSON hợp lệ

----------------------------------------------------------
Bước 5: Build Request Body
----------------------------------------------------------

BuildRequestBody(...)

Chuyển prompt thành request model phù hợp với provider.
