==========================================================
OpenAiResumeParserProvider - Phan Tich Chi Tiet
==========================================================

1. TONG QUAN
----------------------------------------------------------

OpenAiResumeParserProvider la implementation ha tang cua `IResumeParsingAiProvider`.

Muc dich cua no la bien doi resume text da trich xuat thanh du lieu ung vien co cau truc
thong qua mot AI provider tuong thich OpenAI.

Provider nay duoc thiet ke nhu mot lop tang cuong tuy chon:
- Neu AI bi tat, cau hinh sai, timeout, hoac tra ve output khong hop le,
  ung dung co the fallback ve rule-based parsing trong `CandidateService`

----------------------------------------------------------
2. NO TAO RA DIEU GI
----------------------------------------------------------

Service yeu cau AI tra ve JSON co cau truc gom:
- thong tin co ban cua profile
- skills da chuan hoa
- kinh nghiem lam viec
- projects
- educations
- certifications
- languages
- parser notes

DTO dich la `CandidateResumeAiParseDto`.

----------------------------------------------------------
3. PHU THUOC
----------------------------------------------------------

`HttpClient`
- gui request toi AI provider da cau hinh

`OpenAiSettings`
- dieu khien co bat AI hay khong, API key, base URL, model va gioi han ky tu parse CV

`ILogger<OpenAiResumeParserProvider>`
- ghi log loi provider va timeout

----------------------------------------------------------
4. PHUONG THUC CHINH
----------------------------------------------------------

`TryParseResumeAsync(string extractedText, IReadOnlyList<Skill> availableSkills, CancellationToken cancellationToken)`

Luong chinh:
1. validate kha nang dung AI
- flag bi tat
- thieu API key
- extracted text rong

2. xay dung danh sach skill goc co gioi han
- bo muc rong
- loai trung khong phan biet hoa thuong
- sap xep alphabet
- gioi han toi da 250 muc

3. build prompt
- dinh nghia schema JSON dich
- nhac AI khong duoc hallucinate
- uu tien ten skill nam trong master skill list

4. build request body theo tung provider

5. gui HTTP request

6. trich xuat output text that su tu nhieu dang response khac nhau

7. chuan hoa JSON neu bi bao trong markdown fence

8. deserialize thanh `CandidateResumeAiParseDto`

9. tra ve `ResumeParsingAiResult`
- `UsedAi = true` neu thanh cong
- `UsedAi = false` kem `FailureReason` khi phai fallback

----------------------------------------------------------
5. CHIEN LUOC TUONG THICH PROVIDER
----------------------------------------------------------

Service nay ho tro hon mot kieu response.

Nhung helper lien quan:
- `BuildEndpoint()`
- `UsesChatCompletions()`
- `BuildRequestBody(...)`
- `ExtractOutputText(...)`

Nho do, cung mot service co the chay voi:
- OpenAI Responses API
- OpenAI-compatible Chat Completions endpoint
- Gemini/OpenAI-compatible endpoint

----------------------------------------------------------
6. CHIEN LUOC PROMPTING
----------------------------------------------------------

`BuildPrompt(...)` thuc hien nhieu viec quan trong:
- cat ngan CV qua lon theo `MaxResumeParseChars` hoac fallback 12000 ky tu
- cung cap schema JSON nghiem ngat
- dua vao ten skill chuan
- yeu cau suy luan kinh nghiem mot cach than trong
- uu tien `null` / mang rong thay vi tu invent du lieu

Thiet ke nay tot vi giup mapping xuong downstream on dinh hon.

----------------------------------------------------------
7. XU LY THAT BAI
----------------------------------------------------------

Loi AI khong duoc xem la loi nghiep vu gay dung luong.

Nhung truong hop duoc xu ly:
- AI bi tat
- thieu API key
- extracted text rong
- HTTP status khong thanh cong
- output text rong
- JSON payload khong hop le
- timeout
- exception khac

Trong tat ca truong hop tren, service tra ve ket qua that bai co cau truc thay vi nem exception.

Lua chon nay quan trong vi `CandidateService.ParseResumeAsync` van co the tiep tuc
bang fallback parsing va van tra duoc preview dung duoc cho user.

----------------------------------------------------------
8. LOGIC CHUNG VOI OpenAiCopilotProvider
----------------------------------------------------------

Service nay lap lai nhieu helper tich hop provider:
- tao request body
- chon endpoint
- trich xuat output
- chuan hoa JSON co markdown fence

Day la ung vien rat manh cho mot helper/base component OpenAI-compatible dung chung.
