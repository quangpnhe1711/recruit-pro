==========================================================
CandidateService - Phan Tich Chi Tiet
==========================================================

1. TONG QUAN
----------------------------------------------------------

CandidateService la service dieu phoi nghiep vu rong nhat lien quan den mien ung vien.

No bao gom:
- tu dang ky ung vien
- danh sach/chi tiet ung vien cho HR
- tao template import
- import hang loat kem email moi
- doc/cap nhat profile
- quan ly skills va kinh nghiem
- parse va upload CV
- danh gia do day du profile

Class nay vua chua nghiep vu, vua chua rat nhieu logic parsing / mapping.

----------------------------------------------------------
3. LUONG DANG KY / IMPORT
----------------------------------------------------------

`RegisterAsync(...)`

Muc dich:
- tao user
- gan role candidate
- tuy chon tao profile ban dau
- tuy chon upload CV ban dau

Hanh vi quan trong:
- transaction ro rang
- rollback neu that bai
- xoa file da upload neu transaction DB fail

`GenerateImportTemplateAsync()`
- tao file XLSX mau cho import hang loat

`PreviewImportAsync(...)`
- parse file upload va validate tung dong nhung chua ghi DB

`ImportCandidatesAsync(...)`
- validate tung dong
- tao users va profiles cho nhung dong hop le
- gan role candidate
- commit mot lan
- gui email moi sau khi DB thanh cong

Viec tach DB commit va email delivery la hop ly vi loi email khong lam hong du lieu da import.

----------------------------------------------------------
4. QUAN LY PROFILE
----------------------------------------------------------

`GetProfileAsync(Guid userId)`
- tra ve DTO profile day du

`UpdateProfileAsync(...)`
- ap thay doi vao profile
- retry 1 lan neu gap EF concurrency conflict

`UpdateSkillsAsync(...)`
- thay toan bo tap skill cua ung vien trong transaction

`CreateExperienceAsync(...)`
- them mot kinh nghiem vao tai lieu nhung

`UpdateExperienceAsync(...)`
- cap nhat mot muc kinh nghiem theo id

`DeleteExperienceAsync(...)`
- xoa mot muc kinh nghiem theo id

----------------------------------------------------------
5. CAC LUONG LIEN QUAN DEN CV
----------------------------------------------------------

`ParseResumeAsync(...)`

Hanh vi chinh:
- validate input
- trich xuat text thuan theo loai file
- uu tien AI parsing truoc
- fallback sang parse xac dinh khi AI khong kha dung hoac that bai
- tra ve DTO preview de user xac nhan

`UploadResumeAsync(...)`

Hanh vi chinh:
- upload file len storage
- danh dau CV cu khong con la current
- tao resume version moi
- cap nhat timestamp profile/user
- rollback thay doi DB va xoa object da upload neu that bai

`GetResumeDownloadUrlAsync(...)`
- tim profile so huu CV
- sinh presigned URL
