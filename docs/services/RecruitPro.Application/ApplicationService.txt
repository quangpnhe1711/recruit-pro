==========================================================
ApplicationService - Phan Tich Chi Tiet
==========================================================

1. TONG QUAN
----------------------------------------------------------

ApplicationService dieu phoi toan bo vong doi cua ho so ung tuyen.

Service nay ho tro:
- chuan bi man hinh ung tuyen
- nop ho so
- cac thao tac tu phuc vu cua ung vien
- danh sach ho so cho HR
- hang doi va chi tiet review cho manager
- chuyen trang thai quyet dinh ho so
- truy cap CV gan voi ngu canh ho so ung tuyen

----------------------------------------------------------

- `IApplicationRepository`

----------------------------------------------------------
3. LUONG UNG TUYEN CUA UNG VIEN
----------------------------------------------------------

`GetApplyScreenAsync(Guid userId, string jobId)`

Muc dich:
- ghep du lieu cho man hinh truoc khi ung tuyen

Du lieu bao gom:
- tom tat job
- tom tat profile ung vien
- thong tin CV hien tai kem presigned URL
- ket qua kiem tra dieu kien ung tuyen

`ApplyAsync(Guid userId, string jobId, ApplyJobRequest request)`

Luong ghi du lieu:
1. tai job
2. tai profile ung vien
3. kiem tra ho so da ton tai
4. tinh dieu kien ung tuyen
5. dung som neu bi chan
6. tao ho so moi voi trang thai `Applied`
7. luu trong transaction

----------------------------------------------------------
4. QUAN LY HO SO CUA UNG VIEN
----------------------------------------------------------

`GetCandidateApplicationsAsync(...)`
- tai tat ca ho so cua user
- loc trang thai/tu khoa trong bo nho
- xay dung trang thai hien thi, buoc tiep theo va action kha dung cho ung vien

`WithdrawApplicationAsync(...)`
- kiem tra quyen chuyen trang thai theo workflow
- doi trang thai thanh `Rejected`

`AcceptOfferAsync(...)`
- xac thuc dieu kien tra loi offer
- yeu cau da co offer gui di khi trang thai hien tai la `Offer`
- chuyen ho so sang `Hired`
- cap nhat trang thai offer thanh `Accepted`

`DeclineOfferAsync(...)`
- xac thuc ton tai offer da gui
- chuyen ho so sang `OfferDeclined`
- cap nhat offer thanh `Declined`

----------------------------------------------------------
5. MAN HINH CHO HR / MANAGER
----------------------------------------------------------

`GetJobApplicationsAsync(...)`
- danh sach phan trang ho so cua mot job

`GetRecentApplicationsAsync(...)`
- lay 5 ho so moi nhat cua mot job

`GetHrApplicationsAsync(...)`
- danh sach phan trang cap HR voi bo loc department/status/job

`GetManagerReviewQueueAsync(...)`
- xay dung danh sach review cho manager dua tren scoring
- tinh cac chi so tong hop nhu so luong recommended va diem trung binh

`GetApplicationReviewDetailAsync(...)`
- chi tiet day du cua mot ho so

`UpdateApplicationDecisionAsync(...)`
- xac thuc trang thai dich
- kiem tra transition bang workflow
- gan reviewer id neu duoc cung cap
- persist trong transaction

----------------------------------------------------------
6. TRO GIUP FILE / EMAIL
----------------------------------------------------------

`GetApplicationCvAsync(...)`
- tim CV hien tai cua ung vien dua tren ngu canh ho so
- tra ve presigned URL va metadata file

`SendApplicationEmailAsync(...)`
- hien tai chi tao ket qua subject/body da duoc chuan hoa, chua gui email that
- giong preview/placeholder hon la tich hop gui mail thuc su
