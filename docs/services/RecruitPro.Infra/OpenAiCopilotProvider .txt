==========================================================
OpenAiCopilotProvider - Phan Tich Chi Tiet
==========================================================

1. TONG QUAN
----------------------------------------------------------

OpenAiCopilotProvider la implementation cua `IAiCopilotProvider`.

Muc dich cua service nay la dong vai tro cau noi giua ATS System va AI Provider
(OpenAI, Gemini, Azure OpenAI, OpenRouter hoac bat ky OpenAI-compatible API nao).

Service ho tro 2 chuc nang chinh:

1. Xep hang ung vien
- nhan JD, Rules va Candidate Pool
- gui du lieu sang AI
- nhan ket qua danh gia va xep hang

2. Recruiter Copilot Chat
- recruiter dat cau hoi bang ngon ngu tu nhien
- AI tra loi dua tren du lieu JD va Candidate Pool

Toan bo giao tiep voi AI deu di qua service nay.

----------------------------------------------------------
2. CAC THANH VIEN CHINH CUA CLASS
----------------------------------------------------------

`private static readonly JsonSerializerOptions JsonOptions`

Muc dich:
- chuan hoa qua trinh serialize va deserialize JSON

Duoc dung de:
- serialize payload gui len AI
- deserialize ket qua AI tra ve

`private const string OpenAiResponsesSuffix = "/responses";`

Muc dich:
- endpoint mac dinh cua OpenAI Responses API

Vi du:
- `https://api.openai.com/v1/responses`

`private const string OpenAiChatCompletionsSuffix = "/chat/completions";`

Muc dich:
- endpoint cho OpenAI-compatible Chat Completions API

Vi du:
- `https://openrouter.ai/api/v1/chat/completions`
- `https://generativelanguage.googleapis.com/.../chat/completions`

`private readonly HttpClient _httpClient`
- dung de gui HTTP request toi AI provider

`private readonly ILogger<OpenAiCopilotProvider> _logger`
- ghi log request bat dau, hoan tat, that bai va exception

`private readonly OpenAiSettings _settings`
- chua cau hinh AI nhu `Enabled`, `ApiKey`, `Model`, `BaseUrl`, `MaxCandidatesForAi`

----------------------------------------------------------
3. CONSTRUCTOR
----------------------------------------------------------

`public OpenAiCopilotProvider(...)`

Inject:
- `HttpClient`
- `OpenAiSettings`
- `ILogger<OpenAiCopilotProvider>`

Constructor khong chua business logic, chi khoi tao dependency.

----------------------------------------------------------
4. TryCreateRankingAsync
----------------------------------------------------------

Muc dich:
- thuc hien AI ranking

Input:
- Candidate Pool
- Normalized Rules
- Deterministic Ranking
- User Prompt
- Conversation Id

Output:
- `CopilotPromptResponseDto`

Luong tong quat:

Job + Rules + Candidates
            ↓
      Build Prompt
            ↓
       AI Provider
            ↓
      Parse Result
            ↓
CopilotPromptResponseDto

Buoc 1: Validate AI Configuration
- kiem tra AI co duoc bat khong
- kiem tra API key co ton tai khong
- neu khong, tra `null` de ATS fallback ve deterministic ranking

Buoc 2: Gioi han so ung vien
- chi gui toi da so ung vien theo `MaxCandidatesForAi`
- muc dich la tiet kiem token, giam chi phi va tranh vuot context

Buoc 3: Build Payload
- tao object gom `job`, `userPrompt`, `normalizedRules`, `candidates`, `deterministicRanking`
- day la toan bo du lieu AI duoc phep thay

Buoc 4: Build Prompt
- sinh prompt ranking
- yeu cau AI tra dung schema
- khong bo sot ung vien
- moi candidate phai co summary
- auto reject phai nam cuoi
- ket qua phai la JSON hop le

Buoc 5: Build Request Body
- `BuildRequestBody(...)` chuyen prompt thanh request model phu hop voi provider

Buoc 6: Build HTTP Request
- `BuildRequest(...)` tao `HttpRequestMessage` gom URL, auth header va body

Buoc 7: Send Request
- gui request bang `_httpClient.SendAsync(...)`

Buoc 8: Read Response
- doc raw JSON tu `response.Content.ReadAsStringAsync()`

Buoc 9: Extract Output
- `ExtractOutputText(raw)` lay phan text that su tu response
- can co buoc nay vi moi provider co format hoi khac nhau

Buoc 10: Normalize JSON
- `NormalizeJsonPayload(...)` bo markdown fence neu AI tra ve dang ```json ... ```

----------------------------------------------------------
5. CAC HELPER TICH HOP PROVIDER
----------------------------------------------------------

Nhung helper dang dong vai tro adapter cho OpenAI-compatible provider:
- `BuildRequest(...)`
- `BuildRequestBody(...)`
- `BuildEndpoint(...)`
- `UsesChatCompletions()`
- `ExtractOutputText(...)`
- `NormalizeJsonPayload(...)`

Day la nhom logic lap lai rat gan voi `OpenAiResumeParserProvider`.

----------------------------------------------------------
6. GIA TRI THIET KE
----------------------------------------------------------

- Cho phep he thong doi provider ma khong phai sua logic tang application
- Ho tro nhieu kieu endpoint Responses / Chat Completions
- Giu cho copilot co kha nang fallback ve deterministic ranking khi AI khong kha dung

----------------------------------------------------------
7. CO HOI REFACTOR
----------------------------------------------------------

Nhom helper OpenAI-compatible o tren nen duoc dua ve:
- mot helper chung, hoac
- mot abstract base class cho cac provider AI

Loi ich:
- mot noi xu ly su khac biet giua provider
- giam nguy co 2 implementation lech nhau khi request/response format thay doi
