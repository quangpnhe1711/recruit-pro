==========================================================
MinioFileStorageService - Phan Tich Chi Tiet
==========================================================

1. TONG QUAN
----------------------------------------------------------

MinioFileStorageService la implementation ha tang cua `IFileStorageService`.

Nhiem vu cua no la luu tru va truy xuat file rieng tu object storage tuong thich MinIO.

Trach nhiem chinh:
- upload CV ung vien va cac file khac
- tao presigned download URL
- tai noi dung object thanh stream
- xoa object theo kieu best-effort
- dam bao bucket muc tieu ton tai truoc khi thao tac file

----------------------------------------------------------
2. PHU THUOC
----------------------------------------------------------

`IMinioClient`
- thuc thi moi thao tac voi bucket va object

`MinioSettings`
- cung cap ten bucket va thoi gian het han URL

`ILogger<MinioFileStorageService>`
- log upload thanh cong, tao URL, xoa va cac loi

----------------------------------------------------------
3. CAC PHUONG THUC CONG KHAI
----------------------------------------------------------

`UploadFileAsync(Stream stream, string objectName, string contentType)`

Luong xu ly:
1. validate stream va object name
2. dam bao bucket ton tai
3. copy stream vao memory buffer
4. upload buffer bang `PutObjectAsync`
5. tra ve object key da luu

Chi tiet quan trong:
- method nay dua ca stream vao bo nho truoc khi upload
- cach nay don gian hon cho retry/position handling nhung co the ton RAM voi file lon

`GetPresignedUrlAsync(string objectName)`

Luong xu ly:
1. chuan hoa object name hoac URL dau vao
2. dam bao bucket ton tai
3. tao `PresignedGetObjectArgs`
4. ap dung thoi gian het han tu cau hinh
5. tra ve read URL tam thoi

`DownloadFileAsync(string objectName)`

Luong xu ly:
1. chuan hoa object name
2. dam bao bucket ton tai
3. tai object vao `MemoryStream`
4. dua vi tri stream ve dau
5. tra stream cho caller

`DeleteFileAsync(string objectName)`

Hanh vi:
- bo qua input rong
- chuan hoa key
- xoa theo kieu best-effort cleanup
- log warning thay vi nem lai loi MinIO

Dieu nay quan trong trong cac luong rollback, noi cleanup khong nen che mat loi nghiep vu goc.

----------------------------------------------------------
4. CAC HELPER NOI BO
----------------------------------------------------------

`EnsureBucketExistsAsync()`
- kiem tra bucket cau hinh da ton tai chua
- tao lazily neu dang thieu

`GetPresignedUrlExpiryInSeconds()`
- dung gia tri cau hinh neu hop le
- fallback ve `3600` giay

`NormalizeObjectName(string objectName)`
- chap nhan ca object key thuan va full URL
- bo dau `/` o dau
- loai bucket prefix khoi absolute URL
- nem loi neu object name rong

----------------------------------------------------------
5. CAC CALLER THUC TE
----------------------------------------------------------

Nhung noi dung pho bien trong codebase:
- `CandidateService.RegisterAsync`
- `CandidateService.UploadResumeAsync`
- `CandidateService.GetResumeDownloadUrlAsync`
- `ApplicationService.GetApplyScreenAsync`
- `ApplicationService.GetApplicationCvAsync`
- `CopilotService.EnrichPoolWithResumeTextAsync`

----------------------------------------------------------
6. MO HINH THAT BAI
----------------------------------------------------------

Upload / presigned URL / download:
- log roi nem lai exception MinIO

Delete:
- log roi nuot loi MinIO

Su tach biet nay la co chu dich:
- thao tac nghiep vu cot loi phai fail ro rang
- cleanup chi can best-effort

----------------------------------------------------------
7. Y TUONG REFACTOR / CAI TIEN
----------------------------------------------------------

- Tach logic chuan hoa object-key thanh helper dung chung cho file storage
- Can nhac upload streaming truc tiep voi file lon
- Can nhac co buoc bootstrap bucket khi app startup de tranh check ton tai bucket tren moi request
